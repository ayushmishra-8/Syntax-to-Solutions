# Day 032 - Find the Difference

## Problem

Given two strings `s` and `t`, string `t` is generated by shuffling the characters of `s` and adding one extra character.

Return the extra character.

## Approach

I used a HashMap to count the frequency of characters in `s`.

### Steps

1. Traverse string `s` and count each character using a HashMap.
2. Traverse string `t` and check each character's frequency.
3. If a character is not present in the map or its frequency is zero, return that character.
4. Otherwise, decrease its frequency by one.
5. The character that cannot be matched is the extra character.

## Java Solution

```java
class Solution {
    public char findTheDifference(String s, String t) {
        HashMap<Character, Integer> map = new HashMap<>();

        for (int i = 0; i < s.length(); i++) {
            char key = s.charAt(i);
            map.put(key, map.getOrDefault(key, 0) + 1);
        }

        for (int i = 0; i < t.length(); i++) {
            char key = t.charAt(i);

            if (!map.containsKey(key) || map.get(key) == 0) {
                return key;
            }

            map.put(key, map.get(key) - 1);
        }

        return ' ';
    }
}
```

## Example

**Input:**

`s = "abcd"`

`t = "abcde"`

**Output:**

`'e'`

## Complexity Analysis

- **Time Complexity:** O(n), where n is the length of `s`.
- **Space Complexity:** O(1) for the HashMap because the problem uses lowercase English letters, so at most 26 distinct characters are stored.

## Key Takeaway

This problem helped me practice HashMap frequency counting and learn how to track repeated characters by increasing and decreasing their frequencies.
