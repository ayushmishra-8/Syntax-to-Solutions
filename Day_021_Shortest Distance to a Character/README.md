# Day 021 - Shortest Distance to a Character

## Problem

Given a string `s` and a character `c` that occurs in the string, return an array of integers representing the shortest distance from each character in `s` to the given character `c`.

**LeetCode:** #821  
**Difficulty:** Easy

---

## Example

```text
Input:
s = "loveleetcode"
c = 'e'

Output:
[3,2,1,0,1,0,0,1,2,3,4,0]
